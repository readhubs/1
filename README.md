# مصنع الكورسات — محول النص إلى PowerPoint

A client-side PWA that converts a structured Arabic course text file into professional PowerPoint (PPTX) files — one per lecture — with automatic thumbnail generation, all running entirely in the browser with no server or backend required.

## Deployment (GitHub Pages)

1. Fork or upload this repository to GitHub
2. Go to **Settings → Pages**, set source to `main` branch and `/ (root)` folder
3. Your app is live at `https://<username>.github.io/<repo-name>/`

## How to Use

1. Open the app and drag-and-drop (or click to browse) your structured `.txt` course file
2. Review the detected lectures in the preview grid, then click **توليد وتحميل**
3. Download the ZIP containing all PPTX files + course thumbnail, or download each lecture individually
